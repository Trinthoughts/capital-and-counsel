# Capital & Counsel — V1

A static, responsive editorial website for Capital & Counsel.

## GitHub Pages

1. Keep the website files in the repository root.
2. In GitHub, go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main and / (root), then Save.
5. GitHub Pages will publish the site.

## Editing

The sample article is article.html. Replace sample language and figures with verified research before publication. For each new article, copy article.html, rename it, edit it, and add it to the relevant category page and homepage.

## Newsletter

The signup form is a visual placeholder in V1. Connect it to an email provider before launch.

## Editorial standard

Use primary documents and reputable reporting where possible. Clearly distinguish reported facts from analysis and identify sources.
