# Capital & Counsel — V1

A static, responsive editorial website for Capital & Counsel.

## GitHub Pages
1. Keep the website files in the repository root.
2. In GitHub, go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main and / (root), then Save.
5. GitHub Pages will publish the site.

## Writing and publishing articles
The site now includes article-template.html, a reusable HTML template for new articles, and ARTICLE-TEMPLATE.md, which contains the writing and publishing workflow.

The intended workflow is:
1. Write and research the article yourself.
2. Copy article-template.html and rename it using a short, permanent, hyphenated filename.
3. Replace the placeholders with your headline, category, date, dek, article text and sources.
4. Commit the new HTML file to the repository.
5. Add the article to the relevant category page.
6. Add the article to the homepage's Latest analysis section when appropriate.
7. Update Deal Monitor when the article covers a tracked transaction.
8. Check the live site on desktop and mobile.

Capital & Counsel's editorial standard is to use primary documents and reputable reporting where possible, clearly distinguish reported facts from analysis, and identify sources.
